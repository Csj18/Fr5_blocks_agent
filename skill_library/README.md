# skill_library — 技能层

封装原子动作为 ROS 2 Action Server，供规划层调度执行。

## 技能列表

| 技能 | 描述 |
|------|------|
| `pick_skill/` | 抓取技能：基于视觉原料位姿计算抓取点，含预抓取点与力控闭合 |
| `place_skill/` | 放置技能：结合几何推算与 scene_graph 生成安全放置位姿，执行防碰撞路径规划 |
| `base_move_skill/` | 基座移动技能：预留避障逻辑，控制机械臂基座位姿 |

## 设计原则

- 每个技能为独立的 ROS 2 Action Server，可独立调试与复用
- 技能内部封装容错重试逻辑（≤3 次），失败后上报并跳过
- 通过 `.action` 文件定义接口契约（输入参数、反馈、结果）
