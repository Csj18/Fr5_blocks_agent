# memory_layer — 记忆层

维护系统的内部世界模型与任务日志，是"混合感知架构"中负责已搭建结构状态管理的核心模块。

## 模块

- **场景图** (`scene_graph.py`)：维护已搭建结构（块 ID → 位姿 → 属性映射），含视觉校准标记。Place 技能依赖此模块计算目标放置位姿
- **会话日志** (`session_log.py`)：全量任务日志记录，含失败案例，用于后续 RAG 知识库入库与复盘

## 关键作用

- 避免对已搭建积木的重复视觉识别（节约算力）
- 配合 `scene_calibrator` 的局部视觉修正，实现"内部模型 + 视觉校准"闭环
- 抑制误差累积：每层校准偏差，避免高层累积误差
